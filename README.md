# CARTEL INVOICE MAKER

A complete, professional, client-side invoice generator website.

## How to use

1. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari).
2. Fill in your business details, client details, and invoice info.
3. Add / edit / remove line items.
4. Set tax rate and discount if needed.
5. Click **Download PDF** to generate a clean, print-ready invoice.
6. Use **Print Invoice** or **Live Preview** for quick checks.
7. **Save Draft** stores everything in your browser’s local storage (nothing is sent to any server).

## Features

- Dark, modern UI with bold Cartel branding
- Dynamic line items (add / remove / edit)
- Multi-currency support (USD, EUR, GBP, CAD, AUD, INR, NGN, ZAR, RWF, UGX)
- Tax & discount calculations
- Professional PDF generation (html2pdf.js)
- Print-ready layout
- Live preview in a new tab
- Local draft save / load
- Fully responsive
- 100% private – all data stays in your browser

## Tech

- Pure HTML + CSS + JavaScript
- No backend required
- Uses Google Fonts (Inter + Space Grotesk)
- Uses html2pdf.js (CDN) for PDF export

Just open `index.html` and start creating invoices.
